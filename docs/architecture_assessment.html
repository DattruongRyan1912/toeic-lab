🔍 Đánh giá Chi tiết 5 Tầng Công nghệ

1. Tầng Client & Presentation (Vanilla SPA + Pre-rendered SSR)

Frontend hiện tại là một Single-file Monolithic SPA viết hoàn toàn bằng Vanilla JavaScript ES6+, HTML5 và CSS3 variables. Đặc biệt, dữ liệu từ vựng (60 từ) và đề thi ETS Part 5 (30 câu) được biên dịch tĩnh (pre-render) trực tiếp vào DOM tĩnh thông qua Python script scripts/build_full_frontend.py.

Ưu điểm Kỹ thuật

  • First Contentful Paint (FCP) tiệm cận 0ms: Trình duyệt nhận HTML là hiển thị ngay dữ liệu, không bị hiện tượng màn hình trắng chờ tải bundle JS hay chờ gọi API REST.
  • Zero Dependency & Zero Node.js: Không có thư mục node_modules (thường nặng 300MB - 1GB), không sợ lỗi version hay security vulnerability từ npm packages.
  • Offline-Capable TTS: Tận dụng Web Speech API native của trình duyệt để đọc từ vựng tiếng Anh (chuẩn US/UK) mà không tốn băng thông server hay chi phí TTS API.

Nhược điểm & Rủi ro

  • File Size khổng lồ: File docs/index.html hiện dài ~9,700 dòng, tích hợp cả CSS, HTML DOM và logic JS. Khó chia nhánh git (git conflict cao nếu làm việc nhóm).
  • Scope Pollution: Nhiều biến toàn cục (global variables) và hàm gắn vào window, dễ xảy ra va chạm state hoặc khó debug khi logic phình to.
  • Thao tác DOM thủ công: Không có Virtual DOM hoặc Reactive State (như Vue/React), dẫn đến việc phải tự render innerHTML và quản lý addEventListener bằng tay.

2. Tầng Backend & Application (FastAPI + Async Python)

Backend được viết bằng FastAPI (Python 3.10+) chạy trên máy chủ ASGI Uvicorn. Các endpoint được module hóa thành các router độc lập (flashcard_router, ai_coach_router, mock_test_router, audio_router).

3. Tầng Lưu trữ Dữ liệu (SQLite + SQLAlchemy ORM)

Hệ thống dùng SQLite tại server/data/toeic_lab.db với SQLAlchemy 2.0.

  • Đánh giá tính phù hợp: Với mục đích cá nhân tự học (Single-user), SQLite là sự lựa chọn tuyệt vời nhất: zero RAM footprint, không cần cài đặt service daemon, backup đơn giản bằng lệnh copy file .db.
  • Giới hạn kỹ thuật (Bottleneck): SQLite sử dụng cơ chế khóa file (file-level lock) khi ghi. Nếu mở rộng ra cho 50 - 100 người dùng làm bài thi đồng thời và gửi kết quả về cùng lúc, hệ thống sẽ gặp lỗi database is locked (OperationalError). Cần cấu hình WAL Mode (Write-Ahead Logging) hoặc chuyển sang PostgreSQL khi mở rộng.

4. Tầng AI & Đa mô hình (Multi-Model Resilience)

Chiến lược tích hợp AI của dự án rất thông minh và thực dụng:

  • DeepSeek API: Sử dụng cho các tác vụ giải thích ngữ pháp, từ vựng và tự động điền form (tiết kiệm chi phí gấp 5-10 lần so với GPT-4).
  • Gemini 2.5 Flash: Sử dụng cho OCR đề thi qua ảnh (multimodal vision tốc độ cao).
  • Local Fallback Engine: Khi LLM bị timeout hoặc hết quota, service tự động trả về phân tích mẫu dựa trên tập luật (Rule-based heuristics), người dùng không bao giờ thấy lỗi 500.

5. Tầng DevOps & Vận hành (Docker + Volume Mounts)

Ứng dụng được đóng gói trong Docker Compose chạy trên VPS Ubuntu 22.04 LTS (domain https://toeic.truongquocdat.id.vn): 

# docker-compose volume mapping hiện tại
services:
  toeic-app:
    volumes:
      - ./server:/app/server     # Hot reload mã nguồn backend
      - ./docs:/app/docs         # Hot reload file giao diện web

Cách cấu hình mount volume trực tiếp này rất tối ưu cho giai đoạn phát triển nhanh: khi chỉnh sửa file frontend hoặc backend, server cập nhật tức thì mà không cần tốn 3-5 phút build lại Docker image.

⚖️ Bảng Tổng kết Đánh đổi Kỹ thuật (Architectural Trade-offs)

Quyết định Kiến trúc Những gì ĐƯỢC (Wins) Những gì ĐÁNH ĐỔI (Trade-offs)
Vanilla Monolithic SPA (1 file HTML) FCP cực nhanh, zero build setup, không phụ thuộc npm, dễ deploy lên bất kỳ static host nào. Khó maintain khi file vượt 10k dòng, không có TypeScript để type-check, khó viết unit test FE.
Pre-rendered DOM (SSR tĩnh qua Python) Hiển thị dữ liệu 100% ngay khi load trang, không bao giờ bị tình trạng bảng trắng khi API lỗi. Mỗi khi thay đổi dữ liệu seed, phải chạy lại script build trước khi push lên server.
SQLite Database Zero maintenance, không tốn RAM, backup cực kỳ an toàn và dễ dàng. Không hỗ trợ write concurrency cao, không có user permission cấp DB.
Web Speech API thay vì Server TTS Tốc độ phát âm tức thì (0ms latency), không tốn tiền API TTS của cloud. Phụ thuộc vào voice có sẵn trên OS/trình duyệt của người dùng (iOS/Android/Windows có voice khác nhau).

🚀 Lộ trình Tiến hóa Kiến trúc (3-Phase Evolution Roadmap)

Giai đoạn 1: Cá nhân Tự học (Mục tiêu 850+ TOEIC) Giai đoạn Hiện tại

Chiến lược: Giữ nguyên 100% kiến trúc hiện tại! Không nên over-engineering. Kiến trúc này siêu nhẹ, mở tab là học ngay, không tốn thời gian maintain hạ tầng, chi phí VPS $0 (tận dụng server có sẵn).

Giai đoạn 2: Chia sẻ cho Bạn bè / Nhóm học (10 - 100 Users) Khi cần chia sẻ

Nâng cấp cần thiết:

  • Frontend: Chuyển sang Vite + Vue 3 / React + Tailwind CSS. Tách các component riêng: VocabTable.vue, FlashcardDeck.vue, MockTest.vue để code sạch và dễ thêm tính năng.
  • Database: Đổi connection string SQLAlchemy từ sqlite:///toeic_lab.db sang postgresql://... (chạy 1 container Postgres trên Docker).
  • Auth: Bổ sung bảng users và xác thực JWT Bearer Token để mỗi người có tiến độ học và SRS flashcard riêng.
Giai đoạn 3: Hệ thống Luyện thi TOEIC SaaS (1,000+ Concurrent Users) Thương mại hóa

Kiến trúc phân tán chuẩn Enterprise:

  • Redis Cache: Caching bảng xếp hạng, kết quả query đề thi và cache kết quả phân tích AI (tránh tốn token trùng lặp).
  • Task Queue (Celery / ARQ): Xử lý tác vụ AI giải thích đề thi bất đồng bộ qua hàng đợi, không block request HTTP.
  • Object Storage (AWS S3 / Cloudflare R2): Lưu trữ hàng nghìn file audio Part 1, 2, 3, 4 và ảnh chụp đề thi Part 7.

Quyết định Kiến trúc (ADR)

  • Frontend & Web API: Dời hoàn toàn logic HTML tĩnh hiện tại sang Next.js App Router. Sử dụng Next.js làm BFF để quản lý User Session (Auth.js) và Routing phân quyền.
  • Backend Core: Giữ nguyên FastAPI làm Microservice chuyên trách xử lý AI (DeepSeek, Gemini, OCR, Audio TTS). Việc này giúp tách biệt rõ logic Web (TS) và logic AI (Python).
  • Cơ sở dữ liệu: Từ bỏ SQLite (bị bottleneck khi multi-tenant), chuyển lên PostgreSQL. Dùng Prisma/Drizzle (ở Next) hoặc SQLAlchemy (ở FastAPI).

Lộ Trình Triển Khai (Migration Roadmap)

Phase 1: Foundation

Khởi tạo Next.js & Thiết lập Database

  • • Repo: Khởi tạo dự án Next.js (TypeScript, App Router) trong thư mục web/ hoặc cấu hình monorepo.
  • • UI Foundation: Cài đặt Tailwind, Shadcn/UI (Button, Card, Dialog, Toast, Form).
  • • Database: Cài đặt PostgreSQL qua Docker. Setup Drizzle ORM (hoặc Prisma) định nghĩa schema User, Session, MockTest, Flashcard.
Phase 2: Auth & Layout

Hệ thống Đăng nhập & SaaS Layout

  • • Tích hợp NextAuth (Auth.js) / Clerk hỗ trợ đăng nhập Google, Github.
  • • Xây dựng Dashboard Layout: Sidebar điều hướng (Vocab, Mock Test, Roadmaps, Settings), Topbar thông báo.
  • • Phân quyền (RBAC): Admin Role (quản lý câu hỏi, prompt LLM), User Role (học viên).
Phase 3: Migration Data & Modules

Chuyển đổi UI Vanilla sang React/Next.js

  • • Module Sổ tay Từ Vựng: Chuyển UI thêm/xóa/sửa từ vựng thành Form React. Xây dựng logic Review thẻ (thuật toán SRS / SM-2).
  • • Module Thi Thử (Mock Test): Chuyển UI làm bài Part 5. Fetch dữ liệu từ Next.js API Routes (Next API gọi tới FastAPI để kích hoạt AI chấm điểm).
  • • Data Migration: Viết script Python (FastAPI) đọc từ SQLite cũ, map và đẩy lên PostgreSQL mới.
Phase 4: Optimization & Deployment

Tối ưu AI API & Triển khai Production

  • • FastAPI Refactor: Chuyển FastAPI thành Service chỉ nhận request từ Next.js (bảo mật mTLS hoặc internal network trên Docker). Bỏ logic Render HTML khỏi Python.
  • • UI Polish: Sử dụng Framer Motion hoặc GSAP cho các hiệu ứng lật thẻ từ vựng. Tối ưu LCP, SEO/Metadata.
  • • Docker Compose V2: Gói Next.js (BFF), FastAPI (AI Core), PostgreSQL, Redis vào chung một mạng network deploy lên VPS (đã có nginx reverse proxy).

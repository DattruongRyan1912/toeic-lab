Lệnh Vận Hành Nhanh Trên VPS (Cheatsheet)

Xem trạng thái container:
sudo -n docker ps --filter name=toeic-lab
Xem log realtime của Next.js:
sudo -n docker logs -f --tail 50 toeic-lab-web
Xem log realtime của FastAPI:
sudo -n docker logs -f --tail 50 toeic-lab-app
Sao lưu thủ công SQLite Database:
cp server/data/toeic_lab.db server/data/backup_$(date +%s).db

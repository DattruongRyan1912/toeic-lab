1. Báo Cáo Audit Hiện Trạng Dự Án

GAP ANALYSIS
✅ Thế Mạnh Đã Xây Dựng Được
Nền móng nội dung và audio
Tốt
  • Audio Engine 3 Tầng: Đã có 40 file MP3 chất lượng Studio chuẩn ETS (Azure Neural Jenny) + FastAPI microservice có MD5 disk caching.
  • Tư duy Root Cause Analysis (RCA): Đã phân loại 5 bẫy gốc [VOCAB], [GRAMMAR], [PHONETICS], [TRAP], [TIME].
  • Nội dung sư phạm chuẩn: Đã phác thảo 12 chuyên đề cú pháp toán học Part 5 và phương pháp giải đề 1-3.
  • Dockerized: Đã có Dockerfile và docker-compose.yml cho audio backend.
⚠️ Điểm Nghẽn & Giới Hạn Hiện Tại
Cần tái cấu trúc thành Web Platform
Cần nâng cấp
  • Chưa có Database thực sự: Mọi tiến độ, câu sai và thẻ đã thuộc đều lưu ở localStorage trình duyệt, đổi máy hoặc xóa cookie là mất sạch.
  • Kho dữ liệu còn phân mảnh: Mới có 20 Flashcards hardcoded và 1 bài học HTML; chưa có ngân hàng câu hỏi đề thi và bẫy Part 1-7.
  • Chưa có AI Agent chủ động: Chưa có chatbot tích hợp; học viên phải tự chép tay câu sai thay vì có AI tự phát hiện lỗi và bồi đắp kiến thức.
  • Thiếu Vision OCR: Không chụp/gửi ảnh câu hỏi đề thi để AI bóc tách trực tiếp được.
  • Chưa có hệ thống nhắc nhở: Không có notification/cron nhắc học hàng ngày.

2. Kiến Trúc Nền Tảng Mục Tiêu (Target Platform)

FULL-STACK MODULAR MONOLITH

Hệ thống được thiết kế theo kiến trúc FastAPI Monolith + Relational Database (PostgreSQL / SQLite) + AI Multimodal Agent Service, tối ưu để host trên VPS cá nhân của bạn với chi phí tài nguyên thấp nhất nhưng hiệu năng cao nhất:

📐 Sơ đồ phân tầng hệ thống (High-Level Architecture)
💻 TẦNG 1: FRONTEND WEB APP
• Dashboard & Roadmap: Theo dõi tiến độ 24 tuần, KPI số câu hàng tuần.
• Flashcard Studio SRS: Ôn tập ngắt quãng (Spaced Repetition), phát audio MP3 0ms.
• Knowledge Vault: 12 chuyên đề cú pháp, Paraphrase Vault, sổ tay bẫy đề thi.
• Smart Error Log: Quản lý câu sai, phân loại RCA tự động.
• AI Mentor Floating Panel: Chat tương tác, upload ảnh câu hỏi (Vision), nhận phân tích 3 chiều.
⚡ TẦNG 2: FASTAPI & AI AGENT
• REST API Core: Users, Roadmaps, Sprints, Flashcards, Error Logs.
• Proactive AI Agent: Tích hợp DeepSeek / Multimodal Vision LLM.
• Tool-Calling Engine: Cho phép AI tự đọc lịch sử học, tự log câu sai, tự sinh thẻ flashcard.
• TTS Microservice: Azure Neural TTS + MD5 Disk Caching.
• Study Reminder Scheduler: Background worker định kỳ gửi thông báo.
🗄️ TẦNG 3: DATABASE & STORAGE
• Relational Database: SQLite (Local) / PostgreSQL (VPS Docker).
• SQLAlchemy ORM + Alembic: Quản lý migration và quan hệ dữ liệu.
• Disk Cache Storage: /app/cache/*.mp3 lưu trữ audio vĩnh viễn.
• Image Uploads: /app/uploads/questions/ lưu ảnh bài thi học viên gửi lên.

3. Thiết Kế Cơ Sở Dữ Liệu (Relational Database Schema)

POSTGRESQL / SQLITE DDL

Database được chuẩn hóa để lưu trữ đầy đủ toàn bộ hành trình học, từ vựng SRS theo thuật toán Spaced Repetition, lỗi sai RCA và bộ nhớ ngữ cảnh của AI:

SQL DDL SCHEMA (PostgreSQL / SQLite Compatible) 
-- 1. Quản lý Người dùng & Mục tiêu
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    target_score INT DEFAULT 800,
    daily_goal_minutes INT DEFAULT 60,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Lộ trình học (Roadmap & Sprints)
CREATE TABLE roadmaps (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(150) NOT NULL,
    total_weeks INT DEFAULT 24,
    current_week INT DEFAULT 1,
    status VARCHAR(20) DEFAULT 'in_progress'
);

CREATE TABLE sprint_tasks (
    id SERIAL PRIMARY KEY,
    roadmap_id INT REFERENCES roadmaps(id) ON DELETE CASCADE,
    week_number INT NOT NULL,
    category VARCHAR(50) NOT NULL, -- Listening, Reading, Syntax, Vocab
    title TEXT NOT NULL,
    is_completed BOOLEAN DEFAULT FALSE,
    completed_at TIMESTAMP
);

-- 3. Kho tri thức & Flashcards SRS
CREATE TABLE flashcards (
    id SERIAL PRIMARY KEY,
    category VARCHAR(100) NOT NULL,
    word VARCHAR(100) NOT NULL,
    ipa VARCHAR(100),
    word_type VARCHAR(50),
    meaning TEXT NOT NULL,
    collocations TEXT,
    paraphrase_pair TEXT,
    example_sentence TEXT NOT NULL,
    audio_word_url VARCHAR(255),
    audio_sentence_url VARCHAR(255)
);

CREATE TABLE user_flashcard_srs (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    card_id INT REFERENCES flashcards(id) ON DELETE CASCADE,
    repetition_count INT DEFAULT 0,
    ease_factor NUMERIC(4,2) DEFAULT 2.5,
    interval_days INT DEFAULT 1,
    state VARCHAR(20) DEFAULT 'new', -- new, learning, review, mastered
    next_review_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_reviewed_at TIMESTAMP,
    UNIQUE(user_id, card_id)
);

-- 4. Sổ tay Lỗi Sai (Error Log & RCA)
CREATE TABLE error_logs (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    test_id VARCHAR(50), -- e.g. ETS2024_Test01
    part VARCHAR(20) NOT NULL, -- Part 1 -> Part 7
    question_no INT,
    error_type VARCHAR(20) NOT NULL, -- VOCAB, GRAMMAR, PHONETICS, TRAP, TIME
    user_choice VARCHAR(10),
    correct_choice VARCHAR(10),
    question_content TEXT,
    image_url VARCHAR(255), -- Ảnh chụp bài thi nếu gửi qua Vision
    root_cause TEXT NOT NULL,
    key_rule_or_paraphrase TEXT,
    status VARCHAR(20) DEFAULT 'unresolved', -- unresolved, reviewed, mastered
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 5. Lỗ hổng kiến thức mà AI phát hiện (AI Learning Gaps)
CREATE TABLE ai_learning_gaps (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    topic VARCHAR(100) NOT NULL, -- e.g. "Bẫy Similar Sound Part 2", "Rút gọn mệnh đề Part 5"
    error_count INT DEFAULT 1,
    severity VARCHAR(20) DEFAULT 'high', -- low, medium, high, critical
    ai_recommendation TEXT,
    is_resolved BOOLEAN DEFAULT FALSE,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 6. Hội thoại AI Assistant & Agent Memory
CREATE TABLE ai_messages (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    role VARCHAR(20) NOT NULL, -- user, assistant, system, tool
    content TEXT,
    image_url VARCHAR(255),
    tool_calls JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 7. Lịch nhắc nhở (Reminders)
CREATE TABLE study_reminders (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    reminder_type VARCHAR(50) NOT NULL, -- daily_study, review_error_log, srs_due
    scheduled_time TIME NOT NULL, -- e.g. 21:00:00
    message TEXT NOT NULL,
    is_active BOOLEAN DEFAULT TRUE
);

5. AI Mentor Đa Phương Thức & Khả Năng Can Thiệp Tri Thức

DEEPSEEK / MULTIMODAL VISION AGENT

AI không dừng lại ở việc trả lời câu hỏi thông thường. Đây là một Huấn luyện viên cá nhân chủ động (Proactive AI Mentor) được trang bị bộ công cụ (Agent Tools) để tương tác trực tiếp với Database của bạn:

👁️ 1. Khả Năng Vision (Bóc Bẫy Đề Thi Từ Ảnh Chụp)

Học viên chỉ cần chụp ảnh màn hình đề thi hoặc trang sách bài tập và gửi vào khung chat:

1
OCR & Nhận Diện Đề Thi: AI trích xuất câu hỏi, 4 phương án A B C D và ngữ cảnh.
2
Phân Tích Bẫy 3 Chiều: Chỉ rõ vì sao đáp án đúng là đúng, 3 đáp án còn lại là bẫy gì (Similar sound, sai thì, bẫy từ loại), và trích xuất bảng Paraphrase.
3
Tự Động Lưu Vào Sổ Lỗi: Gọi tool log_error_question() lưu trực tiếp vào database mà người dùng không cần gõ lại.
🛠️ 2. Các Agent Tools Can Thiệp Trực Tiếp Vào Hệ Thống
Tên Tool (Function Call) Mục đích sử dụng Dữ liệu can thiệp
get_user_learning_profile() Đọc lịch sử học tập, thống kê điểm số, danh sách các câu sai gần đây Bảng error_logs, ai_learning_gaps
log_error_question() Tự động lưu câu sai kèm nguyên nhân gốc RCA và bài học rút ra Bảng error_logs
create_flashcard() Trích xuất từ mới trong lúc giảng bài và thêm ngay vào bộ thẻ SRS Bảng flashcards, user_flashcard_srs
recommend_remedial_exercises() Chủ động đề xuất 3-5 câu bài tập khắc phục đúng chuyên đề học viên đang yếu Bảng ai_learning_gaps, knowledge_nodes
schedule_study_reminder() Đặt lịch nhắc học viên ôn lại câu sai sau 24h, 3 ngày, 7 ngày Bảng study_reminders

6. Hệ Thống Nhắc Nhở & Theo Dõi Tiến Độ

ACCOUNTABILITY & HABIT LOOP
⏰ Nhắc Nhở Học Hàng Ngày
Daily Ping

Đặt khung giờ cố định (ví dụ 21:00 mỗi tối). Hệ thống gửi Web Push Notification hoặc nhắc nhở trên giao diện kèm thông điệp: "Hôm nay bạn có 15 thẻ Flashcard đến hạn ôn tập và 1 bài tập cú pháp Bài 02 cần hoàn thành!"

🔄 Chu Kỳ Ôn Lỗi Sai (Spaced Review)
Error Retention

Khi bạn làm sai 1 câu, AI lên lịch nhắc ôn lại câu đó sau 1 ngày ➔ 3 ngày ➔ 7 ngày. Câu hỏi chỉ được đóng lại khi bạn làm đúng 2 lần liên tiếp dưới dạng Quiz trắc nghiệm nhanh.

📈 Báo Cáo Tuần Tự Động (Sprint Report)
Weekly KPI

Cuối mỗi tuần, AI tổng hợp: Số từ vựng đã nạp, số câu bài tập đã giải, tỉ lệ phân bổ lỗi sai theo 5 nhóm RCA, và cập nhật % tiến độ hoàn thành lộ trình 24 tuần.

🏗️ Kiến Trúc & Luồng Xử Lý (Listening Engine Architecture)

1. Backend Core Services (`server/`)

  • listening_service.py: Thuật toán so khớp chuỗi SequenceMatcher phân tách từ (correct, misspelled, missing, extra), tính độ chính xác % và phát hiện biến âm Flap-T, Elision (nuốt âm), Consonant-to-Vowel (nối âm).
  • listening_router.py: 3 API chuẩn RESTful:
    • GET /api/listening/exercises: Bộ đề nghe Part 1-3.
    • POST /api/listening/check-dictation: Chấm điểm bài gõ.
    • POST /api/listening/track: Ghi nhận thời gian luyện nghe vào hoạt động ngày.
  • planner.py: Tích hợp hành động học tập kind="listening" điều hướng trực tiếp đến /listening.
  • ai_agent_router.py: Chuẩn hóa auth injection Depends(current_user_id).

2. Frontend Studio (`apps/web/`)

  • app/(dashboard)/listening/page.tsx: Giao diện Studio 2 chế độ:
    • Dictation: Điều khiển tốc độ (0.8x, 1.0x, 1.2x), phím tắt Ctrl+Enter, phân tích token màu theo chuẩn RCA.
    • Shadowing: Ghi âm giọng người học với MediaRecorder API, đếm giờ trực tiếp và so sánh side-by-side với giọng đọc bản xứ.
  • components/layout/sidebar.tsx: Đã cập nhật mục "Luyện Nghe (Audio)" với icon Headphones và badge Dictation.
  • types/index.ts: Đầy đủ interfaces đồng bộ 1:1 với Pydantic backend.

🚀 Hướng Dẫn Vận Hành & Trải Nghiệm Luyện Nghe

Khởi động môi trường

# 1. Chạy Backend FastAPI (port 8000)
./.venv/bin/python -m uvicorn server.main:app --port 8000

# 2. Chạy Frontend Next.js (port 3005)
cd apps/web && pnpm dev

Trải nghiệm tính năng

  1. Truy cập http://localhost:3005/listening trên trình duyệt.
  2. Chọn Chép Chính Tả (Dictation): Bấm Play nghe audio và gõ vào ô nhập văn bản, bấm Ctrl + Enter để kiểm tra diff màu.
  3. Chọn Nói Nhại (Shadowing): Bấm micro thu âm, nhại theo giọng đọc bản xứ và bấm nghe lại để so sánh phát âm.
